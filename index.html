ARCHITECTURE · 3-layer OCR cascade + multi-agent
Layer 1 · pdfplumber
Structured text extraction
Native PDF text parsing. ~240ms/doc. $0 cost. Handles 60–70% of documents without AI.
Layer 2 · Gemini 2.5 Flash
Vision OCR — handwriting
Visual AI for handwritten fields, checkboxes, signatures. ~820ms/page. Covers remaining 30–40%.
Layer 3 · Gemini 2.5 Pro
High-confidence validation
Triggered only when confidence <0.75. ~640ms. Legal-grade accuracy for critical fields.
Agent A · Compliance
Regulatory compliance check
Structured output: compliance_score, campos_faltantes, veredicto (APPROVED / OBSERVATION / REJECTED), justification. Runs in parallel.
Agent B · Anti-Fraud
Anomaly & duplicate detection
Fraud risk score, duplicate probability, pattern alerts. Runs in parallel with Compliance on every single document.
